| 時期 | 出来事 |
|------|--------|
| （時期不明） | もともとGeminiでVSCode実装。デザインが安定せずやり取りが進まず、Claude設計＋Cursor実装に引き継ぐ |

| 2026-08-14〜19 | デザイントークン適用、blocks形式への移行、各書類（手術説明・入院系・胆嚢摘出術など）の本文を紙の承諾書どおり流し込み |

| 2026-08-22 | iPad Safariで保存は成功するのに印刷ウィンドウが開かない不具合を修正。履歴検索をカード表示からテキストリストに変更 |
| 2026-08-24〜25 | 印刷ウィンドウでPDFの印刷が実行されない不具合を修正。印刷は手動2ステップ（PDF表示→共有アイコンからプリント）を正式な流れに。PDF余白・電話番号や緊急連絡先の配置調整、カルテ番号欄の廃止、html2canvasでの文字クリップ・丸数字ズレの修正 |
| 2026-08-25 | 直近のコミット時点。A4 1ページに収まらない・デザインが安定しない・PDF精度への不満が残ったまま |

v1は28コミットで一区切り。技術方式（PDF生成ライブラリ依存）そのものに起因する問題が
繰り返し出たため、作り直しの検討に入った。
